# Day 1: Algorithm Selection Report

## 1. Problem & Data Characteristics
- **Problem Type:** Supervised Regression (predicting continuous numerical targets).
- **Data Scale:** Moderate sample size, structured tabular features.
- **Constraints:** Balance between high predictive accuracy and model interpretability.

## 2. Candidate Models Finalized
1. **Baseline Model (Mean Predictor):** Establishes the minimum performance threshold.
2. **Multiple Linear Regression:** Provides high interpretability and clear feature coefficient analysis.
3. **Ridge & Lasso Regression:** Adds regularization to control overfitting and handle multicollinearity.
4. **Random Forest Regressor:** Non-linear tree ensemble to capture complex feature interactions with reduced variance.
5. **Gradient Boosting Regressor / XGBoost:** Advanced boosting ensembles selected for maximum predictive accuracy.
